## Michael Fusco Personal Site

GitHub Pages/Jekyll personal brand site for Michael Fusco (Chief-Prince-Of-Function).

## Local development

```bash
bundle install
bundle exec jekyll serve
```

## Content editing notes

- Homepage sections are in `index.markdown`.
- About page content is in `about.markdown`.
- Writing index is in `writing/index.markdown`.
- Featured projects are data-driven in `_data/projects.yml`.
- Blog posts stay in `_posts/` and keep their existing URLs.

## Optional assets

- Favicon path is configured as `/assets/images/favicon.png` in `_config.yml`.
- Add that file if desired (recommended sizes: 32x32 and 192x192).
